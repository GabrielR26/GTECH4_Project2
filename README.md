# GTECH4\_Project2

GTECH 4 : Gameplay \& Physique avancée, projet N°02,  12/10/26 au 15/10/26



### Architecture :

* PlayerControllerPlateformer -> PlayerPlateformer (ACharacter)
* Plateform - JumpPad - BalancedBoard - Bumper - Door (double) - Explosive - WreckingBall - TeleportationPipe - PressurePlate - BaseObject (Actor)
* Activable - Interactable (UInterface)



### Gameplay :

Le joueur se déplace de salle en salle, activant des mécanismes basés sur la physique pour résoudre des puzzles et débloquer la suite.

Le joueur peut sauter, attraper des objets et activer des boutons.
